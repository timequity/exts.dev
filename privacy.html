Privacy details

Overview

exts.dev is a collection of browser extensions created by timequity.

We do not treat browsing history, usage patterns, or personal settings as product exhaust to be harvested.

Common principles

  • No tracking - no analytics, usage events, or browsing history collection.
  • No accounts - no sign-up, login, or user profile requirement for core functionality.
  • Local storage only - settings stay in browser storage on your device unless a browser sync feature handles them on your side.
  • No network requests by default - extensions are built to avoid phoning home.
  • Open source - code is publicly auditable on GitHub.

Extension notes

GrayMode stores grayscale settings locally and applies filters on sites you choose.

TabZen keeps sessions and recovery state in browser storage and does not upload your tabs to a remote service.

LightSession trims ChatGPT DOM nodes locally to keep the UI responsive without exfiltrating conversation content.

Third-party services

The website itself is hosted via Cloudflare Pages, so standard infrastructure logging may happen at the hosting layer.

That hosting behavior is separate from the browser extensions, which are designed to avoid sending usage data to us.

What we do not do

✓We do not collect browsing history.
✓We do not run analytics pipelines over extension usage.
✓We do not require account creation for the current extension set.
✓We do not sell user data because there is no backend user-data inventory to sell.

Questions

If something here is unclear, open an issue on GitHub.

Policy updates

If this policy changes, this page will be updated. The goal is to keep the privacy model simple enough that meaningful changes should stay rare.
